# Web Design Experiment 1: GitHub Repository and GitHub Pages

## Objective
To design and develop a responsive, structured webpage using HTML5 and CSS3, and deploy it live on the web using GitHub Repositories and GitHub Pages.

## Technologies Used
- HTML5
- CSS3
- Git
- GitHub & GitHub Pages

## Features
- Semantic HTML structure (header, nav, main, section, footer).
- Responsive styling with modern, clean CSS.
- Smooth navigation across sections.
- Hosted and published via GitHub Pages.

## Project Structure
Project_web/
├── index.html
└── README.md

## Steps Followed
1. Created project directory and initial files (index.html).
2. Initialized Git version control (git init).
3. Committed changes and pushed to remote GitHub repository.
4. Created a feature branch to work on webpage sections and styles.
5. Merged the feature branch back into the main branch.
6. Enabled GitHub Pages under Repository Settings > Pages (Source: Deploy from branch main / root).
